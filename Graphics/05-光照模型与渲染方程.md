## 一、实时渲染中的光照到底在计算什么？

### 1. 为什么一个物体会被我们看到？

物体表面向相机方向存在出射光。光可能由物体自身发射，也可能从其他物体/光源入射后，经表面反射或透射再离开。

在通常的不透明表面中，可以把一个表面点朝相机方向的出射光分为：

- 自发光（Emission）。
- 从其他方向入射并被表面反射的光（Reflection）。
- 对真实材质，还可能涉及透射、次表面散射等，本篇先以表面 BRDF 为主。

一个 Pixel 的最终显示值还经过相机/投影、有限面积采样、曝光和色调映射，**不能把 Shader 输出的 RGB 简单等同于物理世界的“光强”**。

### 2. Local Illumination 与 Global Illumination 有什么区别？

- **Local Illumination：** 主要计算当前点对显式光源的直接响应；传统 Phong/Lambert 实时渲染常属于这一类。
- **Global Illumination（GI）：** 进一步考虑光被其他表面反射、折射或散射之后，再次到达当前点的间接贡献，例如 Color Bleeding、Indirect Diffuse、Indirect Specular。
- **直接光照**不是“点光源才算”，面积光和环境中直接可见的发光面也可以提供直接光。

GI 并非某一个固定算法：Lightmap、Probe、屏幕空间技术、Ray Tracing 和 Path Tracing 都可以近似或计算其中不同部分。

### 3. 为什么经典实时渲染首先讲 Lambert 和 Phong？

Lambert 建立了表面入射光、法线夹角与漫反射之间的联系；Phong/Blinn-Phong 提供简单、易计算的高光形状控制。

它们是理解 BRDF 的重要过渡，但传统 Phong 直接叠加 Ambient/Diffuse/Specular 的写法不一定严格遵守能量守恒，也不等于现代 PBR。

### 4. 为什么光照与着色（Shading）不完全相同？

**Lighting** 侧重光从哪里来、怎样传输；**Shading** 侧重对光照与材质的计算，在 GPU 上可能与纹理、法线、阴影、材质层次、后处理结合。

例如把高光效果画在贴图中，是视觉上的 Shading，但不能说明该效果通过物理光照求解得到。

## 二、Radiometry：必须掌握的四个物理量

### 1. Radiant Flux（辐射通量）是什么？

Radiant Flux 用 `Φ` 表示，描述单位时间传输的辐射能量（功率）：

$$
\Phi=\frac{\mathrm dQ}{\mathrm dt}.
$$

单位：**瓦特（W）**，即 `J/s`。

一个理想光源总辐射功率可以用 Flux 表示，但它不包含向哪个方向发射，也不包含多大面积接受。

### 2. Radiant Intensity（辐射强度）是什么？

Radiant Intensity 用 `I` 表示，是单位立体角内的辐射通量：

$$
\boxed{
I(\omega)=\frac{\mathrm d\Phi}{\mathrm d\omega}.
}
$$

单位：**W/sr**。

它描述光源的**方向分布**。各向同性点光源若总 Flux 为 `Φ`，则：

$$
I=\frac{\Phi}{4\pi}.
$$

这里假设功率均匀分布到完整球面；并不是所有点光源都各向同性。

### 3. Irradiance（辐照度）是什么？

Irradiance 用 `E` 表示，是入射到一个表面单位面积上的 Flux：

$$
\boxed{
E=\frac{\mathrm d\Phi}{\mathrm dA}.
}
$$

单位：**W/m²**。

它是**单位表面面积接受了多少功率**，因而与入射方向相对于法线的夹角有关。

某点从半球所有方向接受入射 Radiance 时：

$$
E(p)=
\int_{\Omega^+}
L_i(p,\omega_i)
\max(0,\mathbf n\cdot\omega_i)
\,\mathrm d\omega_i.
$$

**易错点：** Irradiance 是“入射表面上的总量/面积”，没有像 Radiance 那样保留每个传播方向的信息。

### 4. Radiance（辐亮度）是什么？

Radiance 用 `L` 表示，是与传播方向相关的、单位**投影面积**与单位立体角内的 Flux：

$$
\boxed{
L(p,\omega)=
\frac{\mathrm d^2\Phi}
{\mathrm dA_\perp\,\mathrm d\omega}
=
\frac{\mathrm d^2\Phi}
{\cos\theta\,\mathrm dA\,\mathrm d\omega}.
}
$$

单位：**W/(m²·sr)**。

其中 `dA_perp = cosθ dA` 是表面面积相对于光传播方向的投影；该式默认投影余弦取有效正值。

Radiance 同时包含**位置与方向信息**，是渲染方程描述光传输最核心的量。

### 5. 四个物理量如何记忆？

| 物理量 | 符号 | 单位 | 核心含义 |
|---|---|---|---|
| Radiant Flux | `Φ` | W | 总功率 |
| Radiant Intensity | `I` | W/sr | 每立体角的功率 |
| Irradiance | `E` | W/m² | 每表面面积接收的功率 |
| Radiance | `L` | W/(m²·sr) | 每投影面积、每立体角的功率 |

对于从光源到面片的实际积分，Flux、Intensity、Irradiance、Radiance 是有数学关系但**不能在 Shader 中不经单位检查直接互相替换**的量。

### 6. Radiometry 与 Photometry 有何不同？

- Radiometry 描述电磁辐射能量，常用 W 等物理单位。
- Photometry 根据人眼的光谱视觉灵敏度加权，例如 Lumen（lm）、Candela（cd）、Lux（lx）。
- `Lux = lm/m²` 是照度单位，不等于 Radiance `W/(m² sr)`。
- 把一个游戏光源的 `intensity` 参数设置为某个值，不保证那个值天然以 W 或 cd 为物理单位，要看引擎的光源模型及文档。

**面试追问：** Candela 与 Radiant Intensity 的区别是**人眼视觉加权的光度量**和**纯辐射能量量**，不能一概称它们都是“光强”。

## 三、Solid Angle（立体角）与余弦因子

### 1. 为什么渲染方程需要立体角而不只是普通角度？

二维角度描述圆周上的方向范围；三维光从球面上的一片方向范围到达表面，需要用立体角（Solid Angle）。

单位是 `sr`（球面度），一整个球面共 `4π sr`，一个半球共 `2π sr`。

### 2. 立体角如何定义？

半径为 `r` 的球面面积元 `dA_s` 对应：

$$
\mathrm d\omega=\frac{\mathrm dA_s}{r^2}.
$$

在球坐标里，`θ` 为极角、`φ` 为方位角：

$$
\boxed{
\mathrm d\omega=\sin\theta\,\mathrm d\theta\,\mathrm d\phi.
}
$$

半球积分 `θ∈[0,π/2]`、`φ∈[0,2π)` 的立体角：

$$
\int_0^{2\pi}\int_0^{\pi/2}
\sin\theta\,\mathrm d\theta\,\mathrm d\phi=2\pi.
$$

### 3. 为什么表面入射光要乘 `N·L`？

设一束平行光沿单位方向 `wi` 到达表面，`θ` 是入射方向与表面单位法线之间的夹角。

同一束光照在倾斜的表面上，覆盖的真实表面面积更大，因此**单位表面面积**接收到的功率随投影面积减小：

$$
\mathrm dE =
L_i(\omega_i)\cos\theta\,\mathrm d\omega,
\qquad
\cos\theta=\mathbf n\cdot\omega_i.
$$

在朝外法线半球之外时，采用 `max(0,N·L)` 阻止背面入射的直接反射贡献。

**不是为了视觉上好看才乘 Cosine**，而是源自投影面积的几何关系。

### 4. 表面面积与立体角之间如何转换？

一个距离表面点 `r` 处、法线与连接方向夹角为 `θ_y` 的面积元 `dA_y`，在观察点张成的立体角：

$$
\boxed{
\mathrm d\omega=
\frac{|\cos\theta_y|}{r^2}\,\mathrm dA_y.
}
$$

其中 `cosθ_y` 是面积元朝观察点的投影因子。

这个变换是把**面积光源的面积积分**变为**方向积分**的重要基础，也自然引入距离平方衰减和发光面朝向因子。

### 5. 为什么积分 `cosθ` 在半球上的结果是 π？

$$
\int_{\Omega^+}\cos\theta\,\mathrm d\omega
=
\int_0^{2\pi}\int_0^{\pi/2}
\cos\theta\sin\theta\,\mathrm d\theta\,\mathrm d\phi.
$$

对 `θ` 的积分：

$$
\int_0^{\pi/2}\cos\theta\sin\theta\,\mathrm d\theta
=\frac12,
$$

再乘 `2π`：

$$
\boxed{
\int_{\Omega^+}\cos\theta\,\mathrm d\omega=\pi.
}
$$

这也是 Lambert BRDF 最终包含 `1/π` 的关键原因。

## 四、Radiance 为什么沿真空光线保持不变？

### 1. 这句话的完整前提是什么？

在**无吸收、无散射、无增益**且处于均匀传播条件的自由空间中，几何光学下沿一条无障碍光线的 Radiance 保持不变。

这不意味着照明表面的 Irradiance 不随距离变化，也不意味着真实雾、水、烟中的光不衰减。

### 2. Radiance 不变与平方反比定律为什么不矛盾？

Radiance 是按**投影面积和传播立体角**归一化的方向光密度。沿同一光束传播，几何扩散使截面积增大，但相应张角的变化会抵消，故 Radiance 可保持不变。

而一个固定小物体所接收的总光量，取决于光源对它所张的立体角/可见面积；距离变大时它看到的光源方向范围减小，因此 **Irradiance 可以按距离平方衰减**。

### 3. 能从微小光束守恒解释吗？

对无损微小光束，两端交换的通量一致。若面积元 `x` 与 `y` 之间距离 `r`，投影因子分别为 `cosθx` 与 `cosθy`，有：

$$
\mathrm d\Phi=
L_x\,\cos\theta_x\,\mathrm dA_x
\cdot
\frac{\cos\theta_y\,\mathrm dA_y}{r^2}.
$$

反向从 `y` 观察的相应微小光束也有对称的几何系数；在无损自由传播和传播方向一致的定义下可推出两端 Radiance 相等。

**注意：** 该论证依赖对应的传播方向、无遮挡与局部几何条件；不能把物理意义不同的入射/出射 Radiance 随便设成相等。

### 4. 在游戏开发中有什么用？

- 理解 Environment Map 存放的是各方向的入射 Radiance。
- 明白为何远处环境背景不应该人为套用普通点光源的 `1/r²` 衰减。
- 明白灯光总功率、点光源 Intensity 和被照表面的 Irradiance 为什么不同。
- 理解 Ray Tracing 沿无损光线传播 Radiance 的思路。

## 五、点光、方向光、聚光与面积光

### 1. 点光源为什么常使用平方反比衰减？

各向同性点光源在半径 `r` 的球面上向外发射总功率 `Φ`，球面积为 `4πr²`：

$$
\boxed{
E_{\mathrm{radial}}(r)=\frac{\Phi}{4\pi r^2}
=\frac{I}{r^2}.
}
$$

对朝向为 `n` 的接收面：

$$
\boxed{
E(r)=\frac{I(\omega)}{r^2}
\max(0,\mathbf n\cdot\omega_i).
}
$$

这里的 `I` 是以 W/sr 表示的光源 Radiant Intensity，假设理想点光源和无介质损耗。

### 2. 为什么真实渲染器经常还额外给点光设置 Range？

物理理想点光源不会在某个半径突然归零；实时引擎通常需要一个有限 Influence Range 用于光源剔除、性能预算和美术控制。

例如添加平滑衰减窗：

~~~glsl
float x = distanceToLight / max(lightRadius, 1e-4);
float window = 1.0 - smoothstep(0.8, 1.0, x);
float attenuation = window / max(distanceToLight * distanceToLight,
                                 1e-4);
~~~

**重要：** 这只是可控实时渲染近似，`window` 和近距离 `epsilon` 会偏离理想点光源的纯平方反比定律，不能称为严格物理公式。

### 3. 方向光为什么通常不按每个物体距离做平方反比？

方向光近似来自极远处，照向场景的一小块区域时，入射方向、强度可视为常数。

Shader 常直接提供一个平行方向和该方向的 Irradiance Scale。若把太阳当成有限角大小的真实天体，会涉及面积/立体角和软阴影等更复杂情况。

### 4. Spot Light（聚光灯）为什么还要有方向因子？

聚光灯只在一个锥角范围内提供明显照明。典型实时 Shader 可通过灯光轴和点到灯的方向点乘得到角度，再根据 Inner/Outer Cone 平滑插值一个权重。

这种角度权重与物理光源的角分布 `I(ω)` 有联系，但引擎的 `smoothstep` 形状通常属于可调的近似模型。

### 5. 面积光为什么比点光更复杂？

面积光源由很多发光面积元构成；每个位置到被照点的距离与角度不同。对某个接收点 `x` 的直接反射贡献可写成面积积分：

$$
L_o(x,\omega_o)=
\int_{A_L}
f_r(x,\omega_i,\omega_o)\,
L_e(y,-\omega_i)\,
V(x,y)\,
\frac{
|\mathbf n_x\cdot\omega_i|\,
|\mathbf n_y\cdot(-\omega_i)|
}{\|x-y\|^2}
\,\mathrm dA_y.
$$

其中 `wi=(y-x)/|y-x|` 指向光源、`V(x,y)` 是可见性函数（无阻挡取 1）。

**注意：** 这里展示的是**面积光源对一点的直接反射项**，省略其他入射光和该表面的 Emission；对于单面发光/反射还应把点积限制在有效半球。

### 6. 为什么面积光更自然地产生软阴影？

一个表面点可能看到光源面积的一部分，另一部分被遮挡。能到达的光源面积比例和角度分布连续变化，形成 Umbra / Penumbra。

“把点光阴影的边缘做模糊”可以近似软阴影观感，但不等同于对实际面积光源可见性积分的严格求解。

## 六、局部光照：Lambert 漫反射

### 1. Lambertian Surface 的核心假设是什么？

Lambert 表面对于给定的入射 Irradiance，其**出射 Radiance 与观察方向无关**，即理想漫反射分布在可见半球的各方向上是常量。

它不是说物体从任意方向观察时像素一定完全同亮：还有入射光方向、可见性、投影面积、曝光等因素。

### 2. 为什么常见漫反射 Shader 里出现 `max(N·L,0)`？

Irradiance 具有入射方向余弦权重：

$$
\mathrm dE=L_i(\omega_i)\max(0,\mathbf n\cdot\omega_i)
\,\mathrm d\omega_i.
$$

因此传统实时近似：

~~~glsl
float NdotL = max(dot(N, L), 0.0);
vec3 diffuse = albedo * lightColor * NdotL;
~~~

能表达**几何投影衰减**，但如果 `lightColor` 代表物理 Irradiance 且 `albedo` 表示反射率，上式还缺少 Lambert BRDF 的 `1/π`，不能把它当作严格的物理散射表达式。

### 3. 为什么 Lambert BRDF 是 `ρ/π`？

设表面的漫反射反照率/反射率为 `ρ∈[0,1]`，定义其 BRDF 为常数 `c`，则所有出射方向的反射能量比例为：

$$
\rho =
\int_{\Omega^+} c\,\cos\theta_o\,\mathrm d\omega_o.
$$

因为半球余弦积分为 `π`，所以：

$$
\rho=c\pi
\qquad\Longrightarrow\qquad
\boxed{f_r=\frac{\rho}{\pi}.}
$$

这里 `ρ` 可为随波长变化的量，RGB 材质中通常按各颜色通道近似处理。

### 4. Lambert 的直接光计算长什么样？

如果在某个方向上拥有合适的入射 Radiance 分布，需要对方向积分；对于**理想点光源**等离散灯光，Shader 常用已经折算为表面入射的 `I/r²` 等量：

$$
L_o^{\mathrm{point}}=
\frac{\rho}{\pi}\,
\frac{I}{r^2}\,
\max(0,\mathbf n\cdot\omega_i)\,V.
$$

此式中 `I` 是 Radiant Intensity（W/sr），`V` 是可见性（0 或 1 的理想情况）。它没有把单个 `I` 误认为一个普通方向的有限 Radiance 值。

### 5. 为什么常说“Lambert 反射是视角无关的”？

`f_r=ρ/π` 不依赖 `wo`；如果固定表面位置和入射照明，朝各方向的出射 **Radiance** 相同。

这不代表材质无法产生轮廓明暗变化，也不意味着 BRDF 在任意物理场景下都能代表真实表面的漫反射行为。

### 6. 为什么给半球均匀环境 `Li=L` 时输出是 `ρL`？

$$
L_o=
\int_{\Omega^+}
\frac{\rho}{\pi}\,L\,\cos\theta\,\mathrm d\omega
=
\frac{\rho L}{\pi}\cdot\pi
=
\boxed{\rho L}.
$$

这个结果既能验证 Lambert 的 `1/π` 归一化，也可以作为后续 Monte Carlo 积分的正确性测试。

## 七、Phong 与 Blinn-Phong：经验光照模型

### 1. 传统 Phong 模型通常包含什么？

经典的**经验式 Phong Shading** 常写成：

$$
C =
k_a C_a+
k_d C_l\max(0,\mathbf n\cdot\mathbf l)+
k_s C_l\max(0,\mathbf r\cdot\mathbf v)^s.
$$

其中：

- `ka`：环境项系数；`Ca` 是经验环境常量。
- `kd`：Diffuse 系数；`Cl` 是灯光颜色/强度参数。
- `ks`：Specular 系数。
- `s`：Shininess/Exponent，控制高光集中程度。
- `r`：把**入射传播方向 `-l`** 相对于法线反射后的单位方向。
- `v`：表面指向相机的单位方向。

通常还应考虑 `N·L>0`、Shadow、Light Range 等条件；把它当成一个方便控制视觉效果的经验公式，而非精确能量守恒的 BRDF。

### 2. Phong 反射方向如何计算？

取 `l` 为**从表面指向光源**的向量，真实入射传播方向是 `-l`，则：

$$
\boxed{
\mathbf r=
-\mathbf l+2(\mathbf n\cdot\mathbf l)\mathbf n.
}
$$

GLSL 可用 `reflect(-L,N)`，注意 `reflect(I,N)` 的第一个参数应是**入射传播方向**。

### 3. Phong 高光指数越大意味着什么？

`s` 增大，高光只在 `r` 与 `v` 更接近时显著，形状更尖锐；`s` 减小，高光分布更宽。

但这个指数与现代 PBR 中的 Roughness 没有跨模型统一的一一映射。

### 4. Blinn-Phong 为什么使用 Half Vector？

定义从表面向外的单位方向 `l` 和 `v`，二者相加后归一化：

$$
\boxed{
\mathbf h=\frac{\mathbf l+\mathbf v}
{\|\mathbf l+\mathbf v\|}.
}
$$

高光因子改为：

$$
S_{\mathrm{Blinn}}=
\max(0,\mathbf n\cdot\mathbf h)^{s_b}.
$$

当 `l≈-v` 时 Half Vector 退化，工程实现要处理接近零的长度。

### 5. Phong 与 Blinn-Phong 的 Exponent 可以直接相同吗？

不能保证相同指数下高光宽度一致。两者测量角度不同：Phong 以反射向量 `r` 为基准，Blinn 以 Half Vector `h` 为基准。

某些条件下常使用约 `s_blinn≈4*s_phong` 的经验关系作为相近宽度的初始估计，但这个关系不是严格、通用、对任意方向都成立的变换。

### 6. 为什么传统 Ambient Term 不是真实间接光照？

经验 Ambient 常为 `constantColor * materialColor`，没有求解环境遮挡、来自哪一方向、间接反射、遮蔽或空间变化。

它可以用来补亮阴影，但不会自然产生色彩反弹、室内角落遮蔽和真实的环境光贡献。IBL、Lightmap、Irradiance Probe 等是更物理有据的替代思路。

### 7. Phong Shading、Gouraud Shading 与 Phong Reflection Model 的区别？

这是面试中的命名陷阱：

- **Flat Shading：** 对一个面使用近似统一的法线/着色结果。
- **Gouraud Shading：** 顶点计算光照并在三角形内插值颜色。
- **Phong Shading：** 通常指在片元级别插值法线并计算光照。
- **Phong Reflection Model：** 使用 Diffuse 与 `(R·V)^s` 等项的经验反射模型。

**Phong Shading 不等于必须使用 Phong Reflection Model。** 完全可以在片元级别运行 Lambert/PBR BRDF。

## 八、BRDF：从经验高光进入物理散射

### 1. BRDF 的严格定义是什么？

BRDF（Bidirectional Reflectance Distribution Function，双向反射分布函数）描述：给定入射方向的**微分 Irradiance**，在某个出射方向产生多少微分 Radiance。

$$
\boxed{
f_r(p,\omega_i,\omega_o)=
\frac{\mathrm dL_o(p,\omega_o)}
{\mathrm dE_i(p,\omega_i)}.
}
$$

因为：

$$
\mathrm dE_i=
L_i(p,\omega_i)
|\mathbf n\cdot\omega_i|
\,\mathrm d\omega_i,
$$

所以 BRDF 的单位通常是 `sr^-1`。

**解释：** BRDF 不是无量纲“反射概率”；虽然有时图形管线把它当成颜色系数使用，它本质上是方向之间的散射密度。

### 2. BRDF 依赖哪些量？

一般写成 `fr(p,wi,wo)`：

- 表面位置 `p`。
- 入射方向 `wi`。
- 出射方向 `wo`。
- 材质参数，例如 Albedo、Roughness、IOR、法线、各向异性等。

对各向异性材质还要关心局部切线基；真实光谱模型可能以波长为额外维度。

### 3. BRDF 的 Helmholtz Reciprocity（互易性）是什么？

对满足互易性假设的常见反射材质：

$$
\boxed{
f_r(p,\omega_i,\omega_o)=
f_r(p,\omega_o,\omega_i).
}
$$

即交换入射/出射方向，BRDF 不变。

但不要说**世界上所有光学材质都必须如此**：某些非互易系统、特殊光学行为或非典型参与过程并不适用通常假设。

### 4. 什么是 Energy Conservation（能量守恒）？

对无主动增益的被动表面，从任意一个固定入射方向入射的能量，反射到各出射方向的总比例不能超过 1：

$$
\boxed{
\int_{\Omega^+}
f_r(p,\omega_i,\omega_o)
|\mathbf n\cdot\omega_o|
\,\mathrm d\omega_o
\le1.
}
$$

对仅含反射、没有透射的表面，低于 1 的部分可能被吸收等。如果还考虑透射，则必须把传输贡献也纳入完整能量账本。

**易错点：** BRDF 某个方向上的数值**可以大于 1**（单位是 `sr^-1`）；受限制的是经过余弦积分后的总反射能量比例，不是每方向的数值必小于 1。

### 5. BRDF 与 BSDF、BTDF 有什么关系？

- BRDF：反射方向分布。
- BTDF：透射方向分布。
- BSDF：统称表面散射，包含反射和透射。

此外 BSSRDF 用于描述入射/出射位置也可能不同的次表面散射，不能用单点 BRDF 直接表示所有皮肤、蜡和大理石效果。

### 6. 理想镜面反射有普通有限的 BRDF 值吗？

理想镜面只在一个确定方向反射，从连续方向分布角度需要 **Dirac Delta** 来表示，是奇异分布而非普通光滑的有限函数。

Path Tracing 常用针对 Delta BSDF 的离散采样处理；不应将“完美镜面 BRDF = 1”当作严谨的方向散射定义。

### 7. Lambert 为什么是合法 BRDF？

`fr=ρ/π` 是方向常数：

- 具有通常 BRDF 单位 `sr^-1`。
- 交换入射/出射方向不改变数值（互易性）。
- 反射半球余弦积分等于 `ρ≤1`，满足能量守恒。

这三个检查是判断一个新的反射模型是否物理合理的好起点。

### 8. 为什么“Diffuse + Specular”要考虑能量分配？

同一份入射光不能被材质在反射与折射/吸收通道中无限重复使用。

经验式 `diffuse + specular` 如果两个分量各自随意设置，可能导致半球积分超过 1；现代 PBR 通常采用更符合 Fresnel 与微表面理论的能量分配。

具体的 `F`、`D`、`G` 和 Metallic Workflow 留到第六篇详细推导。

## 九、Rendering Equation：必须逐项解释

### 1. 标准表面渲染方程怎么写？

对不透明表面上朝向当前半球的法线 `n`：

$$
\boxed{
L_o(p,\omega_o)=
L_e(p,\omega_o)+
\int_{\Omega^+}
f_r(p,\omega_i,\omega_o)
L_i(p,\omega_i)
(\mathbf n\cdot\omega_i)
\,\mathrm d\omega_i.
}
$$

这里的 `Ω+` 是 `n·wi>0` 的上半球，因此公式中的余弦在积分范围内非负。

### 2. 每一项代表什么？

| 符号 | 含义 | 典型单位 |
|---|---|---|
| `p` | 当前表面点 | m 等空间单位 |
| `wi` | 表面点朝向入射光来源的方向 | 单位向量 |
| `wo` | 表面点朝向观察者的出射方向 | 单位向量 |
| `Lo` | 向 `wo` 出射的 Radiance | W/(m²·sr) |
| `Le` | 自发光 Radiance | W/(m²·sr) |
| `Li` | 沿 `wi` 方向入射的 Radiance | W/(m²·sr) |
| `fr` | BRDF，描述方向散射比例密度 | sr^-1 |
| `n·wi` | 入射余弦投影因子 | 无量纲 |
| `dω` | 立体角微元 | sr |

### 3. 为什么积分是整个半球，而不是只算最近一个光源？

即使当前表面只被一盏灯直接照亮，仍可能受到墙壁反射、地面反弹、环境照明等影响。从全部入射方向累积 Radiance，才能描述完整的表面散射。

传统实时 Forward Light Loop 通常只选择显式灯光，**相当于对光照来源和积分做了近似、拆分或预计算**。

### 4. 为什么要加 Emission？

发光物体即使完全没有外来照明，也能产生出射 Radiance。对发光面来说，直接观察到的颜色贡献包含 `Le`。

但是**给 Emissive Material 写了亮色**不代表它自动照亮附近所有物体；这需要 GI 系统、发光面采样、Lightmap 或其他实现。

### 5. 为什么 Li 仍是未知函数？

某个入射方向上的 Radiance 往往来自另一表面的出射 Radiance。沿光线寻找上一个表面 `q`，无损自由传播时：

$$
L_i(p,\omega_i)=L_o(q,-\omega_i)
$$

（约定 `wi` 指从 `p` 指向 `q`，所以 `-wi` 是从 `q` 指向 `p` 的传播方向；忽略障碍、介质损耗和背景情形。）

因此所有表面上的出射光互相依赖；渲染方程实际上是一个**积分方程**，这就是全局光照比单次局部 BRDF 计算复杂得多的根源。

### 6. 直接光照和间接光照如何从方程中区分？

对某个表面点 `p`，入射光可按来源分成：

- Direct：来自直接可见的发光源（或者特定引擎定义的直接光项）。
- Indirect：来自其他非发光/反射表面再次散射的光。

因此可以写成：

$$
L_o=L_e+L_{\mathrm{direct}}+L_{\mathrm{indirect}}.
$$

这是一种实用的传输路径分解；不同引擎对天空光、环境探针、预计算反射等在架构上的分组命名可能不同。

### 7. 渲染方程为什么不能直接穷举所有方向？

连续半球有无穷多个方向，场景几何、BRDF 和遮挡函数往往复杂，不能对每个方向都精确求和。

常用方式包括：

- 对显式少量灯光直接求和。
- 在规则离散方向上数值积分或预计算卷积。
- 用 Monte Carlo 对积分做随机估计。
- 使用预计算 GI、Probe、Lightmap、Importance Sampling 等降低运行时工作量。

## 十、Visibility、Shadow 与几何项

### 1. 为什么 BRDF 明明能算反射，物体却可能处于阴影？

BRDF 只描述**光到达表面后怎样反射**，而没有单独保证入射方向上真的存在一条无遮挡的光路。

常通过可见性函数 `V(p,y)` 表示两点间是否无遮挡：

- 完全可见：`V=1`。
- 完全遮挡：`V=0`。
- 某些过滤/半透明模型中可为连续的透射近似，但需额外定义。

### 2. Rendering Equation 里为什么没显式写 Visibility？

标准表面方程中的 `Li` 已经是**实际到达该点**的入射 Radiance，遮挡影响隐含在入射 Radiance 中。

把方程改写为“对潜在发光点积分”或做 Direct Light Sampling 时，才通常要显式乘 `V`。

**易错点：** 若 `Li` 已经包含遮挡后的结果，再无条件乘一遍同样的 Shadow/Visibility 可能重复计算。

### 3. 两个面元之间的 Geometry Term 是什么？

从 `x` 处朝向 `y`，令 `r=|x-y|`、`ω=(y-x)/r`。面积互相传输中常见：

$$
\boxed{
G(x,y)=
\frac{
|\mathbf n_x\cdot\omega|\,
|\mathbf n_y\cdot(-\omega)|
}{r^2}.
}
$$

在单面反射/发光情况下，只有有效朝向上的余弦才贡献能量；实际常用 `max(0,...)` 并结合 `V(x,y)`。

这一项由两个投影余弦和平方反比立体角关系构成，不是额外神秘的材质参数。

### 4. 为什么点光与面积光的 Shader 实现看起来不同？

理想点光源方向贡献是奇异的，通常直接求：

~~~text
BRDF * LightIntensity / distance² * NdotL * Visibility
~~~

面积光源则要在其表面上对 `BRDF × Emission × Geometry × Visibility` 积分或近似积分。

方向光也有自己的理想化离散光源贡献形式；不能拿点光公式中的 `1/r²` 机械套用到方向光。

## 十一、从渲染方程到数值积分

### 1. 为什么实时渲染需要“积分近似”？

渲染方程积分的被积函数由四部分共同决定：

1. 当前材质 BRDF。
2. 从不同方向到来的入射 Radiance。
3. 表面法线与入射方向的 Cosine 权重。
4. 阴影、反射路径等隐含的可见性与光传输。

其中很多函数随方向剧烈变化。对整个连续半球求精确解析积分通常不可行，需要采样、预计算或其他数值近似。

### 2. 最简单的离散 Riemann Sum 怎么写？

把半球划成 `N` 个小立体角区域，选一个代表方向 `ωi`，积分近似为：

$$
L_o\approx
L_e+
\sum_{i=1}^{N}
f_r(p,\omega_i,\omega_o)
L_i(p,\omega_i)
\max(0,\mathbf n\cdot\omega_i)\,
\Delta\omega_i.
$$

这种公式明确说明：**每一个采样方向都应该乘以它所代表的立体角权重**。若采用非均匀方向划分，不能无条件把所有权重都当成一样。

### 3. 为什么不能“随机选几个方向直接平均 BRDF × Li”？

因为半球上的均匀立体角分布、余弦加权分布等采样策略不同，样本在方向空间出现的**密度**不同。

如果忽略 Sampling PDF 而直接平均，通常会造成有偏的结果。Monte Carlo 估计器必须按实际采样概率密度修正权重。

### 4. PDF 的单位为什么重要？

若采样的是三维表面外向方向 `ω`，概率密度通常相对于立体角 `dω` 定义：

$$
P(\omega\in A)=\int_A p_\omega(\omega)\,\mathrm d\omega.
$$

`p_ω` 的单位是 `sr^-1`，满足：

$$
\int_{\Omega^+}p_\omega(\omega)\,\mathrm d\omega=1.
$$

如果是按**面积**采样灯光位置，PDF 的单位则是 `m^-2`；二者不能未转换就放进同一个 MIS 公式中比较。

## 十二、Monte Carlo Integration：必须会推导

### 1. Monte Carlo 估计器是什么？

给定任意积分：

$$
I=\int_{\Omega} f(x)\,\mathrm dx.
$$

若按照合法、归一化且在被积函数非零处具有正密度的 PDF `p(x)` 抽取独立样本 `X_i`，则：

$$
\boxed{
\widehat I_N=
\frac1N\sum_{i=1}^{N}
\frac{f(X_i)}{p(X_i)}.
}
$$

因为期望：

$$
\mathbb E\left[\frac{f(X)}{p(X)}\right]
=\int_\Omega p(x)\frac{f(x)}{p(x)}\,\mathrm dx
=\int_\Omega f(x)\,\mathrm dx=I.
$$

所以在满足积分存在等条件时，这是一个**无偏估计器**。

### 2. 将渲染方程写成 Monte Carlo 估计器

将积分中的函数定义为：

$$
g(\omega_i)=
f_r(p,\omega_i,\omega_o)
L_i(p,\omega_i)
\max(0,\mathbf n\cdot\omega_i).
$$

则：

$$
\boxed{
\widehat L_o=
L_e+
\frac1N\sum_{k=1}^{N}
\frac{
f_r(p,\omega_k,\omega_o)
L_i(p,\omega_k)
\max(0,\mathbf n\cdot\omega_k)
}{
p_\omega(\omega_k)
}.
}
$$

这里采样的 `ω_k` 必须遵从 `p_ω`。采样 PDF、BRDF 和方向 Cosine 要使用一致的空间和测度。

### 3. 为什么采样 PDF 要出现在分母？

采样密度高的方向会被抽中更多次，若不除以 PDF 就会被重复过度计入；采样密度低的方向出现次数少，但每次命中会获得更高的校正权重。

这样的加权，使平均结果恢复原本积分的贡献。

**注意：** 小 PDF 会让权重变大，如果 `f/p` 波动剧烈，会产生较大的方差和亮点噪声（Fireflies）。

### 4. Monte Carlo 的误差与样本数有什么关系？

对独立同分布、方差有限的样本，样本均值的方差：

$$
\mathrm{Var}[\widehat I_N]
=\frac{\mathrm{Var}[f(X)/p(X)]}{N}.
$$

因此其标准差大致随 `1/sqrt(N)` 下降：

$$
\boxed{
\mathrm{Std}[\widehat I_N]
\propto \frac1{\sqrt N}.
}
$$

要把典型噪声标准差减半，在简单独立采样模型下往往需要约 4 倍样本，而非仅增加一倍。

实际 Path Tracing 还会受可见性不连续、光源分布、重要性采样、低差异序列和去噪等影响。

### 5. Unbiased 与 Low Variance 是一个概念吗？

不是：

- 无偏（Unbiased）：在所定义模型与期望下，估计量的期望等于真实积分。
- 方差低（Low Variance）：每次采样结果更稳定、更接近平均值。
- 一些实时或离线近似可能有意引入偏差，以显著减少噪声/计算时间。

例如对 Monte Carlo 超大权重做硬截断（Firefly Clamping）通常可能引入**偏差**，不能再无条件宣称估计器严格无偏。

## 十三、半球均匀采样与余弦加权采样

### 1. 均匀半球采样的 PDF 是多少？

半球立体角是 `2π sr`，所以均匀相对立体角的 PDF：

$$
\boxed{
p_{\mathrm{uniform}}(\omega)=\frac1{2\pi},
\quad \omega\in\Omega^+.
}
$$

样本不需要按 `θ` 均匀选取，因为立体角微元是 `sinθ dθ dφ`；**角度 θ 均匀不等于球面立体角均匀**。

### 2. 均匀半球采样如何从两个随机数生成方向？

令 `u1,u2` 独立、均匀分布于 `[0,1)`：

$$
z=u_1,\qquad
\phi=2\pi u_2,\qquad
r=\sqrt{1-z^2}.
$$

构造法线朝向局部 `+Z` 的样本：

$$
\boxed{
\omega=(r\cos\phi,r\sin\phi,z).
}
$$

其 PDF 是半球常数 `1/(2π)`。

### 3. Cosine-Weighted Hemisphere Sampling 的 PDF 是多少？

Lambert 积分中存在 `cosθ` 因子。一个自然的 PDF 是：

$$
\boxed{
p_{\mathrm{cosine}}(\omega)=
\frac{\cos\theta}{\pi},
\quad \omega\in\Omega^+.
}
$$

因为余弦半球积分为 `π`，该 PDF 归一化：

$$
\int_{\Omega^+}\frac{\cos\theta}{\pi}\,\mathrm d\omega=1.
$$

这种采样倾向于选取法线附近方向，减少大量接近切线的低贡献样本。

### 4. 如何生成余弦加权半球方向？

一种常见方法：先均匀采样单位圆盘，再映射到半球。

给两个独立均匀随机数 `u1,u2`：

$$
r=\sqrt{u_1},\qquad
\phi=2\pi u_2.
$$

$$
\boxed{
\omega=
\left(
r\cos\phi,\,
r\sin\phi,\,
\sqrt{1-u_1}
\right).
}
$$

此方向在局部 `+Z` 半球，PDF 为 `cosθ/π`。要用于任意表面法线 `N`，需构造局部正交基并转换到世界空间。

### 5. 为什么余弦采样特别适合 Lambert？

Lambert BRDF `fr=ρ/π`，代入 MC 单样本权重：

$$
\frac{f_r\,L_i\,\cos\theta}{p_{\mathrm{cosine}}}
=
\frac{(\rho/\pi)L_i\cos\theta}{\cos\theta/\pi}
=
\boxed{\rho L_i}.
$$

在正 PDF 区域，`cosθ` 与 `1/π` 正好抵消。对常量环境 Radiance `Li=L`，每个样本的权重均为 `ρL`，理论上不存在由方向采样造成的方差。

**重要限定：** 若环境光、可见性或 BRDF 其他因素随着方向变化，仍可能有噪声；这里说的零方差仅限于常量环境与理想 Lambert 等特定条件。

### 6. 如何理解 Importance Sampling（重要性采样）？

尽量让采样 PDF 的形状接近被积函数的贡献分布，让大贡献区域被更频繁地抽到。

- Lambert：优先对 Cosine 因子采样。
- GGX Specular：可基于微表面法线分布或可见法线分布采样。
- Environment Map：可按亮度与 Solid Angle 建立分布。
- Area Light：可在发光面上采样并通过几何项计算贡献。

重要性采样提升效率，但必须确保采样 PDF 正确，否则会引入系统性偏差。

### 7. 为什么每个方向都不能简单 `pdf = 1/N`？

`1/N` 是离散候选集合上每个离散索引被选中的概率（若等概率），而连续半球方向的 PDF 是**相对立体角的概率密度**，具有 `sr^-1` 单位。

例如均匀半球 PDF 应为 `1/(2π)`，不是 `1/采样数`。Monte Carlo 外面的 `1/N` 与 PDF 分母承担不同作用，不可混淆。

## 十四、面积光采样、PDF 转换与 Next Event Estimation

### 1. 按面积采样面积光源时，PDF 是什么？

若某发光面可采样面积为 `A`，并进行面积均匀采样，PDF：

$$
p_A(y)=\frac1A.
$$

单位是 `m^-2`，因为随机变量是面积上的一个位置 `y`，而不是方向 `ω`。

### 2. 怎么把面积 PDF 换成立体角 PDF？

利用：

$$
\mathrm d\omega=\frac{|\mathbf n_y\cdot(-\omega_i)|}{r^2}\,\mathrm dA_y.
$$

由概率守恒 `p_ω dω = p_A dA`：

$$
\boxed{
p_\omega(\omega_i)=
p_A(y)\frac{r^2}
{|\mathbf n_y\cdot(-\omega_i)|}.
}
$$

要求光源面积元与当前点之间有有效几何关系，分母为零时需要按支持集处理。

**面试高频陷阱：** 把 `pdfArea` 当作 `pdfSolidAngle` 放进 BRDF 方向积分，会产生错误结果，并且单位也不一致。

### 3. 按面积采样一点后的直接光贡献是什么？

对发光面 `A_L`，采样到 `y`，定义 `ωi=(y-x)/r`：

$$
\boxed{
\widehat L_{\mathrm{direct}}=
\frac{
f_r(x,\omega_i,\omega_o)\,
L_e(y,-\omega_i)\,
V(x,y)\,
|\mathbf n_x\cdot\omega_i|\,
|\mathbf n_y\cdot(-\omega_i)|
}{
r^2\,p_A(y)
}.
}
$$

这是单个**面积采样**贡献，若采样多个点还要取平均；若采用单面发光/反射，两个余弦因子要按有效半球截断。

### 4. Next Event Estimation（NEE）在做什么？

在某次表面路径命中时，除了继续按 BRDF 采样下一方向，还**主动选择一个光源或光源表面点**，测试其到当前点的可见性，并估计一个直接光照贡献。

好处：对于很小的面积光源，单纯 BRDF 采样恰好击中光源的概率很低；NEE 可以更有针对性地取样直接光。

### 5. 为什么 NEE 和“增加一个光源采样”不能无脑叠加？

如果既通过 BRDF 路径击中了光源，又单独通过 NEE 为同一传输路径添加直接光贡献，且没有对应的组合规则，就可能**重复计算直接光**。

正确方案包括：

- 对不同传输路径进行不重复的分项设计。
- 将不同采样策略通过 MIS 权重组合。
- 对 Delta Light 或特定采样器按各自支持集正确处理。

具体实现依 Path Tracer 的路径计数约定。

## 十五、多重重要性采样（MIS）入门

### 1. 为什么只有 BRDF Sampling 或只有 Light Sampling 都不稳定？

- BRDF Sampling 对尖锐镜面方向可能有效，但对很小的面积光往往很难命中。
- Light Sampling 对小光源有效，但在强镜面 BRDF 下，随机采样的光源方向大多不符合高贡献反射方向。
- 环境贴图可能存在特别亮的太阳区域，单一均匀采样也不高效。

两种策略都能采到同一类贡献时，可以组合，避免某一种策略在特定材质/场景下出现极高方差。

### 2. MIS 的基本思想是什么？

假设有多个采样策略，第 `j` 个策略 PDF 为 `pj(x)`，抽取 `nj` 个样本。对同一个积分，可按权重函数 `wj(x)` 把不同策略的估计贡献组合。

正确的 MIS 权重通常要求对有贡献的位置，各可用策略权重之和为 1，并使用**相同测度**的 PDF。

### 3. Balance Heuristic 的公式是什么？

对 `n_j` 个来自策略 `j` 的样本：

$$
\boxed{
w_j(x)=
\frac{n_j p_j(x)}
{\sum_k n_k p_k(x)}.
}
$$

在各策略可用于同一积分、PDF 正确定义并且处理了零支持集等前提下，这样分配权重可以构成无偏估计器。

### 4. Power Heuristic 与 Balance Heuristic 有什么区别？

Power Heuristic 常用指数 `β=2`：

$$
\boxed{
w_j(x)=
\frac{[n_j p_j(x)]^\beta}
{\sum_k[n_kp_k(x)]^\beta}.
}
$$

它会更偏向“当前方向 PDF 更大”的采样策略。在很多常见 Direct Lighting 场景中可以降低方差，但**不是每个场景都一定优于 Balance**。

### 5. 什么情况下不能照搬 MIS 公式？

必须关注：

- 两种 PDF 是否对同一测度（Area vs Solid Angle）。
- 是否一个策略抽样的是 Delta 光源/Delta BSDF。
- 是否存在某策略无法生成的方向。
- 是否对同一贡献做了重复计数。
- 样本数量、采样策略概率和返回的实际 PDF 是否一致。

对理想点光源、完美镜面等 Delta 情况，通常需要特殊的路径策略与权重处理，不能简单代入普通连续密度数值。

### 6. 实时引擎需要掌握 MIS 到什么程度？

如果岗位偏实时渲染管线：应理解 PDF/重要性采样与方向/面积测度转换，能够说出 MIS 为什么降低直接光方差。

如果面试涉及 Ray Tracing、Path Tracing、GI 或 Offline Renderer：建议进一步掌握 Path-Space Estimation、BSDF Sampling、Light Sampling 和 MIS 的具体实现细节。

## 十六、GLSL 示例：将光照概念落到正确单位

### 1. 一个简单但明确的 Lambert 点光函数

下方输入约定：

- `normalWS` 是世界空间单位法线（调用内部会防御式归一化）。
- `positionWS` 与 `lightPositionWS` 使用相同世界空间长度单位。
- `lightIntensity` 是按 RGB 通道近似的**Radiant Intensity**，不是任意“灯光颜色乘亮度”。
- `albedo` 是 Linear RGB 中的漫反射反照率。

~~~glsl
const float PI = 3.14159265358979323846;

vec3 EvaluateLambertPointLight(
    vec3 positionWS,
    vec3 normalWS,
    vec3 lightPositionWS,
    vec3 lightIntensity,
    vec3 albedo,
    float visibility)
{
    vec3 toLight = lightPositionWS - positionWS;
    float distance2 = max(dot(toLight, toLight), 1e-6);
    vec3 L = toLight * inversesqrt(distance2);
    vec3 N = normalize(normalWS);

    float NdotL = max(dot(N, L), 0.0);
    vec3 irradiancePerCosine = lightIntensity / distance2;
    vec3 brdf = albedo / PI;

    return brdf * irradiancePerCosine
         * NdotL * visibility;
}
~~~

**说明：** 这是一段教学函数。`distance2` Clamp 不是理想点光的严格奇点行为；有限灯具半径、灯光角分布、发光光谱和实际引擎单位制需要另外定义。

### 2. 如果把光源参数叫 Radiance，会出现什么问题？

常见实时 Shader 直接写：

~~~glsl
vec3 radiance = lightColor * lightStrength / distance2;
vec3 Lo = brdf * radiance * NdotL;
~~~

从工程习惯看能工作，但**变量命名是否物理准确**要看 `lightStrength` 代表什么。若它实际是点光源的 Radiant Intensity，那么 `I/r²` 是接收方向的辐照度系数（尚未乘表面余弦），不是一个可直接按普通立体角积分的连续方向 Radiance。

面试时比起纠结引擎历史命名，更重要的是讲清公式的输入、单位与假设。

### 3. GLSL 的 Phong / Blinn-Phong 如何写？

~~~glsl
vec3 EvaluateLegacyBlinnPhong(
    vec3 N, vec3 L, vec3 V,
    vec3 albedo, vec3 lightColor,
    float shininess, float specularStrength)
{
    N = normalize(N);
    L = normalize(L);
    V = normalize(V);

    float NdotL = max(dot(N, L), 0.0);
    if (NdotL <= 0.0)
        return vec3(0.0);

    vec3 Hsum = L + V;
    if (dot(Hsum, Hsum) < 1e-8)
        return albedo * lightColor * NdotL;

    vec3 H = normalize(Hsum);
    float highlight = pow(max(dot(N, H), 0.0),
                          shininess);

    vec3 diffuse = albedo * lightColor * NdotL;
    vec3 specular = lightColor * specularStrength
                  * highlight;
    return diffuse + specular;
}
~~~

此函数是**经验式可视化模型**，并未对 Diffuse/Specular 做严格能量归一化，也没有保证物理单位；不要把它标注成 Cook-Torrance PBR。

### 4. 如何用常量环境验证 Lambert 实现？

假设整个入射半球的 Radiance 都是常量 `L_env`，理想 Lambert 理论输出应为：

$$
L_o=\rho L_{\mathrm{env}}.
$$

若代码用数值半球积分得到接近 `ρπ L_env`，很可能漏掉了 Lambert 的 `1/π`。

反过来，如果结果偏暗 `π` 倍，也可能重复施加了这个归一化系数。

## 十七、C++ 示例：Cosine-Weighted Hemisphere Monte Carlo

### 1. 为什么这里使用局部空间？

半球采样可先假设表面法线为局部 `+Z`，通过构造正交基将样本旋转到实际世界空间法线。

这样随机方向公式与场景坐标变换分离，更容易测试 PDF 和归一化是否正确。

### 2. 余弦半球采样和 PDF 的最小示例

以下示例基于 GLM 与 C++ 标准库；传入的随机数应来自**两个相互独立、均匀分布于 [0,1) 的样本**。

~~~cpp
#include <cmath>
#include <algorithm>
#include <random>
#include <glm/glm.hpp>
#include <glm/gtc/constants.hpp>

struct DirectionSample
{
    glm::vec3 direction;
    float pdfSolidAngle;
};

// Cosine hemisphere, local +Z as normal
DirectionSample SampleCosineHemisphere(float u1, float u2)
{
    const float r = std::sqrt(u1);
    const float phi = 2.0f * glm::pi<float>() * u2;

    const float x = r * std::cos(phi);
    const float y = r * std::sin(phi);
    const float z = std::sqrt(std::max(0.0f, 1.0f - u1));

    return {glm::vec3(x, y, z),
            z / glm::pi<float>()};
}
~~~

理论上 `pdf = cosθ/π`，而不是 `1/(2π)`。

### 3. 如何用 ONB 将样本转到世界空间？

一种简单且直观的正交基（Orthonormal Basis，ONB）构造法：

~~~cpp
glm::vec3 LocalToWorld(
    const glm::vec3& localDir,
    const glm::vec3& normalWS)
{
    const glm::vec3 N = glm::normalize(normalWS);
    const glm::vec3 axis =
        (std::abs(N.z) < 0.999f)
        ? glm::vec3(0.0f, 0.0f, 1.0f)
        : glm::vec3(0.0f, 1.0f, 0.0f);

    const glm::vec3 T =
        glm::normalize(glm::cross(axis, N));
    const glm::vec3 B = glm::cross(N, T);

    return T * localDir.x +
           B * localDir.y +
           N * localDir.z;
}
~~~

输入法线必须非零并保持有限值。高性能 Path Tracer 可进一步使用更稳定/更廉价的 ONB 构造算法。

### 4. 如何用采样估计常量环境的 Lambert 出射 Radiance？

为了单元测试，首先取 `Li=L_env`，`fr=ρ/π`：

~~~cpp
glm::vec3 EstimateConstantLambert(
    const glm::vec3& albedo,
    const glm::vec3& environmentRadiance,
    int sampleCount,
    std::mt19937& rng)
{
    std::uniform_real_distribution<float> uniform(0.0f, 1.0f);
    glm::vec3 sum(0.0f);

    for (int i = 0; i < sampleCount; ++i)
    {
        auto s = SampleCosineHemisphere(uniform(rng), uniform(rng));
        const float cosine = std::max(0.0f, s.direction.z);

        if (s.pdfSolidAngle > 0.0f)
        {
            glm::vec3 fr = albedo / glm::pi<float>();
            sum += fr * environmentRadiance
                 * (cosine / s.pdfSolidAngle);
        }
    }

    return sum / static_cast<float>(sampleCount);
}
~~~

**预期：** 结果接近 `albedo * environmentRadiance`，对有效的 Cosine Sample 理论上每次权重相同。由于边界浮点值、随机数实现和有限精度，具体单次结果可能有很小的数值误差。

### 5. 为什么不应该直接把上面的 MC 采样放进每像素 Fragment Shader？

这段代码主要用于**算法理解与离线/Compute 实验**。传统实时 Forward/Deferred Shading 通常依赖有限光源列表、Shadow Map、Probe、IBL 预积分等方式，而不是每像素直接进行大量随机半球射线查询。

如果有硬件 RT/Compute GI，则会考虑采样、时空重用、去噪、帧间积累和性能预算；这是更大的系统设计问题。
