- **C++ 进阶：** 类与对象、资源管理与异常、模板与泛型编程、STL、现代 C++、编译链接与运行机制、多线程与内存模型。
- **计算机图形学：** 数学基础、变换、光栅化、着色、光照、阴影、PBR、渲染管线。

## 复习方式

1. 先阅读对应主题文档。
2. 阅读完成后，通过选择题、代码分析题、纠错题和模拟面试追问检验掌握程度。
3. 根据答题情况补充薄弱知识点，并持续更新文档。
